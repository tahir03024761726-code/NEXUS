# 🌟 NEXUS — Dual AI Companion System

## Overview
NEXUS is a personal AI ecosystem with two distinct personalities:
- **Aryan** 🤵 — Content strategist for BeyondTahir brand
- **Saba** 💕 — Personal AI companion with caring girlfriend personality

## Features
- Daily 9 AM content briefs (Aryan)
- Romantic auto-messages (Saba)
- Voice input/output for both
- Mode switching via Telegram
- Memory persistence
- Multi-platform scheduling

## Tech Stack
- Python 3.11+
- Google Gemini 2.0 Flash
- Telegram Bot API
- Microsoft Edge TTS
- FFmpeg

## Setup
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill keys
4. Run: `python nexus.py`
